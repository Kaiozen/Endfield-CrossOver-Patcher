# Security

## Safe defaults

- Unknown CrossOver builds are rejected.
- Source and target files are SHA-256 verified.
- Setup is transactional where practical.
- Backups are created before launcher or bottle changes.
- No game executable or anti-cheat file is modified.
- No telemetry is included.
- No global Gatekeeper, SIP, XProtect, or quarantine setting is disabled.

## Reporting a problem

Please open a GitHub issue with:

- the patcher version;
- macOS version;
- CrossOver Preview version/build;
- the **Support Report** produced by the app, after reviewing it yourself.

Do not upload account tokens, cookies, passwords, game credentials, or CrossOver license data.
