# Wine-derived compatibility data

`Resources/Profiles/endfield-preview-20260717-r11.profile.json` contains
version-bound replacement data derived from modified Wine modules. It is not a
copy of CrossOver, and it cannot function without the user's own exact supported
CrossOver Preview installation.

- Wine: https://gitlab.winehq.org/wine/wine
- Wine licensing: https://www.winehq.org/license

  https://www.codeweavers.com/crossover/source

  https://github.com/stoicswe/Endfield_FineWine

Wine-side research credited in `THIRD_PARTY_NOTICES.md`. CrossOver proprietary
components, GRYPHLINK, Endfield, ACE, and Game Porting Toolkit are not included
in the repository or release package.
